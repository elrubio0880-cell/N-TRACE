# NØTRACE 3.0 — PROJECT CONTEXT

## Visión General
NØTRACE 3.0 es una plataforma educativa y de diagnóstico técnico en ciberseguridad, privacidad digital y arquitectura de redes construida con React 19, TypeScript, Tailwind CSS y un servidor Express (`server.ts`) que provee verificación real de IP pública (`/api/connection` vía IPinfo).

## Pilares del Ecosistema
1. **NØTRACE Methods (`/metodos`)**: Programas técnicos estructurados paso a paso con objetivos prácticos y laboratorios CLI.
2. **NØTRACE Toolkit (`/herramientas`)**: Arsenal de 21 herramientas catalogadas en 5 laboratorios, incluyendo el **VPN Inspector** cartográfico Natural Earth (`/herramientas/vpn-inspector`), **Crypto Lab**, **Network Lab** y **Privacy Lab**.
3. **NØTRACE Campus (`/campus`)**: Entorno de aprendizaje con reproductor de lecciones, terminal interactiva, seguimiento de avance y certificados por mérito.
4. **NØTRACE Vault (`/billetera`)**: Arquitectura conceptual y visual del sistema económico de doble unidad (`NØBYTE` y `NØCORE`).
5. **NØTRACE Operations (`/misiones`)**: Sistema de misiones técnicas y 7 rangos de operador (`01 — INITIATE` a `07 — ZERO`).
